# 시흥 교통관제 시제품

시흥시 중부권 스마트교차로 18곳을 지도에서 찾고, 가상 교차로의 녹색시간 배분을 시험할 수 있습니다. 웹 화면은 React와 TypeScript로 구성하고, FastAPI가 정적 파일과 기존 Python 배분 엔진을 함께 제공합니다.

## 로컬 실행

저장소 최상위 폴더에서 실행합니다. Node.js 22.12 이상과 uv가 필요합니다.

```sh
npm --prefix system/frontend ci
npm --prefix system/frontend run build
uv run --python 3.13 --with-requirements system/backend/requirements.txt python -m uvicorn system.backend.web:app --host 127.0.0.1 --port 8765
```

브라우저에서 [로컬 관제 화면](http://127.0.0.1:8765/)을 엽니다. 프런트엔드를 수정하면서 확인하려면 API 서버를 켠 상태에서 다른 터미널에서 `npm --prefix system/frontend run dev`를 실행하고 Vite가 표시하는 주소를 엽니다.

## 화면과 자료

- **[시내 교차로 CCTV](http://127.0.0.1:8765/#cctv)**는 시흥시 중부권 6개 행정동(월곶·군자·장곡·능곡·연성·목감) 안에서 시흥시와 경기도가 공개하는 시내 교차로 카메라를 표시합니다. 2026년 11월 23일 경기도교통정보센터 공개 목록의 좌표를 행정동 경계와 대조하고, 권역 내 48개 지점의 제공기관을 대조했습니다. 시내 지상 교차로와 접근로를 확인한 14대(시흥시 13대, 경기도 1대)를 등록했습니다. 목감사거리는 센터에 ‘목감지하차도’로 등록되어 있습니다. 목감IC 앞과 목감지하차도사거리는 시흥시 신호제어기 목록과 대조했습니다. [시흥시 교통신호제어기 설치 현황](https://www.data.go.kr/data/15167736/fileData.do) 등록 ID, 명칭과 좌표가 맞는 지점만 표시합니다. 고속도로 사업자 카메라, IC·램프와 지하차도 본선을 비추는 지점은 운영 대상에서 제외합니다. [등록 카메라](data/central_intersection_cameras.json) · [경기도교통정보센터 지도](https://gits.gg.go.kr/web/map/webMap.do) · [행정동 경계 기준본(2026-10-01)](https://github.com/vuski/admdongkor/tree/master/ver20261001)
- **AI 분석 모드**는 CCTV 팝업 왼쪽 위에서 켭니다. 브라우저가 재생 중인 프레임에서 승용차, 이륜차, 버스, 화물차를 검출합니다. 상자 아래쪽 중심이 관측 차로 안에 들어오면 해당 차로에 배정합니다. 카메라 ID별로 수동 지정한 기본 차로를 영상 크기에 맞춰 표시합니다. 영상 밝기나 차량 검출 여부로 차로를 숨기지 않습니다. 공용 기본값은 차로 설정 파일에 보관하고, 팝업에서 직접 지정한 차로는 해당 브라우저에 카메라별로 저장합니다. ‘기본 차로로’를 누르면 공용 설정으로 돌아갑니다.
- **물왕교차로**는 목감동 방향 우회전 전용·직진 2개·좌회전 전용과 시흥시청 방향 직진 2개·우회전 합류를 구분합니다. 방향과 용도는 사용자 확인을 반영했고, CCTV에서 차선과 교통섬을 대조해 관측 영역을 지정했습니다. 목감동 방향은 차로가 갈라지기 전의 후방 접근로도 따로 확대해 차량을 셉니다. 파란 점선 안의 차량은 앞쪽 차로 수에 중복해서 더하지 않습니다. 주간에는 먼 차량일수록 더 크게 확대해 검사합니다. 같은 화각에서 정차 차량 후보가 세 프레임에 걸쳐 같은 위치에 잡히면 약한 검출도 집계에 포함합니다. 낮에 보이는 파란 안내판은 판면 색과 테두리 모양까지 대조합니다. 후방 접근로의 마름모와 방향 화살표는 차가 없는 영상에서 얻은 도색 무늬를 기준으로 확인합니다. 검출 상자 안의 아스팔트까지 일치할 때만 차량 후보에서 제외합니다. 나무에 가린 구간에서는 차량을 놓칠 수 있습니다. 전체 화면은 원본에서 검출하고 차로를 확대해 다시 검사할 때는 방향 자막의 획을 주변 픽셀로 메웁니다. 자막·안내판·신호등에 생긴 차량 상자는 위치와 윤곽이 함께 일치할 때 제외합니다. [차로 영역](frontend/src/traffic-ai/camera-lanes.json) · [고정물 보정 스크립트](frontend/scripts/calibrate_mulwang.py)
- **월곶교차로**는 정왕IC 방향의 직진 두 차로를 화면 뒤쪽 굽은 구간부터 정지선까지 관측합니다. 우회전 전용 차로는 폭이 넓어지기 시작하는 지점부터 교통섬 옆 정지선까지 따로 셉니다. 시청 방향은 직진 두 차로를 관측합니다. 정왕IC 방향의 먼 차량은 더 좁은 영역에서 한 번 더 확대해 검사합니다. 상자 옆의 번호는 이번 영상 안에서 같은 차량을 따라가는 추적 번호입니다. 정지선을 지난 차량도 횡단보도와 우회전 통로에서 계속 추적합니다. 신호 대기 중에는 검출 당시의 차체 무늬가 영상의 같은 자리에 보이는지 확인해 상자와 번호를 유지합니다. 검출이 뜸한 정차 차량도 차례로 확대해 다시 확인합니다. 재생이 잠시 멈추면 마지막 화면의 상자를 유지합니다. 재생을 다시 시작하거나 다음 클립으로 넘어갈 때는 새 화면의 차체 무늬와 위치를 대조해 같은 차량의 번호를 이어갑니다. 차가 화면 가장자리에 걸치면 보이는 부분에만 상자를 표시합니다. 차체 여러 곳의 무늬로 상자의 위치와 크기를 갱신하고, 검출이 비거나 새 움직임이 나타나면 그 주변을 확대해 모델로 다시 검사합니다. 혼잡도는 각 차로에서 검출된 뒤 영상으로 위치를 확인한 차량을 기준으로 계산합니다. 짙은 그림자 속 차량의 상자가 끊기거나 그림자까지 포함할 수 있습니다.
- **시흥경찰서사거리**는 군자동 방향의 직진 두 차로에 중앙선 쪽 좌회전 전용 차로가 먼저 생기고, 이어서 바깥쪽에 우회전 전용 차로가 생기는 구조를 반영했습니다. 연성2교차로 방향은 1·2차로만 관측합니다. 보도 쪽 주차 가능 차로는 차량 표시와 혼잡도 집계에서 제외합니다. 야간에는 차량 상자 안의 마름모·방향 화살표·차로 점선과 그 주변 아스팔트가 빈 도로의 기준 영상과 일치하는지 확인합니다. 차체가 도색을 덮으면 차량 후보를 유지합니다. 연성2교차로 방향 E·F차로 사이의 신호등은 뒷면과 상자 안의 주변 노면이 함께 보일 때 고정물로 처리합니다. 파란 안내판과 차로 위로 돌출된 가로등도 위치와 영상 무늬를 대조합니다. 군자동 방향에서 차가 안내판 뒤로 들어가면 마지막 진행 방향으로 예상 출구를 다시 검사합니다. 최대 3초 안에 위치와 차체 무늬가 맞으면 같은 추적 번호를 잇습니다. 완전히 가린 동안에는 새 차로 집계하지 않으며, 차가 다시 보여도 충분히 구분하기 어려우면 번호가 바뀔 수 있습니다.
- 두 지점의 차로 구성은 사용자 확인을 반영했고, 분기 위치와 정지선은 주간 영상에서 직접 표시했습니다. 새로 생기는 전용 차로의 점유 구간은 인접한 직진 차로의 폭을 기준으로 나눕니다. 별도 주간 영상에서 표시한 차량 상자와 검출 상자를 대조한 결과, 월곶 정왕IC 방향 후방은 18개 중 2개에서 11개로, 시흥경찰서사거리는 9개 중 3개에서 5개로 일치 사례가 늘었습니다. [표본과 대조 방법](data/cctv_analysis_validation.json)
- **이동 차량 상자**는 재생 프레임 시각에 맞춰 표시합니다. 전체 화면의 검출 결과가 나오면 먼저 그리고, 차로 확대 검출이 진행되는 동안 연속 영상에서 밝기 무늬가 일치하는 위치로 상자를 옮깁니다. 월곶·물왕·시흥경찰서에서는 화면 차량과 차로별 대수를 같은 시점의 상자로 표시합니다. 한 차량은 한 차로에만 속하며, 물왕에서 분기 전 후방 접근로에 있는 차는 목감동 방향 합계에 한 번 더해집니다. 서행·정지 판정에는 현재 영상으로 위치를 확인한 차량을 사용합니다. 차종 근거가 약한 상자는 먼저 ‘차량’으로 표시해 바로 집계합니다. 차종이 확인된 뒤에는 다른 차종이 서로 다른 영상 시각에서 반복해 우세할 때만 갱신합니다.
- **차로별 혼잡도**는 관측 차로의 세로 6구간 중 차량이 검출된 구간의 비율을 영상 시간 기준 최근 최대 5초 동안 평균한 값입니다. 1.5초 이상 표본이 쌓인 뒤 표시합니다. 점유 비율 30% 미만은 낮음으로 표시합니다. 60% 이상이면 검출 차량의 절반 이상을 추적하고 그중 절반 이상이 서행·정지로 관측될 때 높음으로 표시합니다. 서행·정지는 1.25초 이상 연결된 검출 상자의 이동량을 화면 속 차량 크기로 나눠 추정합니다. 세 교차로에서는 서행·정지 차량이 현재 차량의 절반 이상이면서 차로당 4대 또는 방향당 6대 이상이면 해당 차로나 방향의 대기 혼잡을 높음으로 표시합니다. 이 기준은 시범 운영용입니다. 현장의 신호 단계나 실제 대기 길이는 따로 측정해야 합니다. 강한 반사광, 짙은 어둠, 화각 변경, 정지·재연결 때는 해당 수치를 보류합니다. 최근 클립을 제공하는 지점은 해당 클립의 재생 시점 기준입니다. 차로별 검출 정확도는 현장 정답 자료와 대조해야 합니다.
- **차량 검출 모델**은 COCO로 학습한 YOLOX-Tiny입니다. 배포본은 원본 ONNX의 합성곱 가중치를 채널별 8비트로 저장하며 실행할 때 float32로 복원합니다. CCTV 팝업을 열면 브라우저가 압축된 모델과 실행기를 병렬로 준비하고, 토글을 켰을 때부터 영상을 분석합니다. 데이터 절약 모드와 2G 연결에서는 토글을 켤 때 준비합니다. 분석을 끄면 프레임 처리를 멈추고, 모델을 최대 1분간 메모리에 보관해 재실행과 카메라 전환에 사용합니다. 분석용 프레임과 탐지 결과는 기기 안에서 처리합니다. [원본 모델](https://github.com/Megvii-BaseDetection/YOLOX/releases/tag/0.1.1rc0) · [가중치 변환](frontend/scripts/pack_yolox.py) · [라이선스](frontend/src/models/analysis-licenses.txt)
- **분석 검증(2026-11-23 저녁)**은 카메라 7대의 서로 다른 15프레임에서 판독 가능한 차로 28개를 대상으로 진행했습니다. 접근로별 확대 감지와 중복 제거를 적용한 뒤 차로당 차량 수 평균 절대오차는 0.50대에서 0.32대로, 단일 프레임 점유율 평균 절대오차는 5.95%p에서 4.76%p로 줄었습니다. 4프레임·8차로는 방식 선택 뒤에 추가 판독했습니다. 같은 저녁 영상에서 Codex가 차량 위치를 표시한 소표본이며, 서행·정지 분류와 혼잡 등급의 현장 정확도는 별도 검증이 필요합니다. 별도 주행 영상 비교에서는 야간 CCTV 4대의 12프레임에 표시한 차량 위치 47개 중 IoU 0.5 이상 일치하는 화면 상자가 8개에서 28개로 늘었습니다. [프레임별 판독과 비교값](data/cctv_analysis_validation.json)
- **스마트교차로 목록**의 18곳 중 8곳은 70m 이내에서 촬영 지점까지 확인한 CCTV와 연결합니다. 나머지 조사 지점에는 현장 영상 미확인 상태를 표시합니다. 지도 설정에서 조사 지점을 겹쳐 볼 수 있습니다. [시흥시 스마트교차로 현황](data/siheung_smart_intersections_2025-11-05.csv)
- **영상 재생**은 브라우저가 센터의 공개 재생 주소로 직접 연결합니다. 직접 연결이 실패할 때만 Odroid가 요청 범위부터 중계합니다. 최근 MP4 영상은 재생 중인 클립이 끝나기 전에 다음 클립을 미리 준비합니다. 센터에서 아직 갱신하지 않았다면 같은 장면이 나올 수 있습니다. 운영 목록의 이름과 좌표는 `SISILJI_CAMERA_CACHE_DIR`에 보관할 수 있습니다. 기존 권역 밖의 녹화 자료는 저장소에 연구 원본으로 보관하며 웹 빌드에는 화면에서 사용하는 자산만 포함합니다.

### 현장 자료와 실험

- **[둔대교차로 실측 사례](http://127.0.0.1:8765/#simulation/dundae)**는 시흥 장현 체육센터 교통영향평가의 2024년 3월 29일 방향별 통과량과 현시 시간을 사용합니다. 07~08시 자료로 준비한 대기열에서 08~09시의 고정 신호와 자동 배분을 비교합니다. 현시별 허용 이동류와 실제 대기열은 공개표에서 확인되지 않았습니다. 저장소에서 `python3 -m system.backend.dundae_case`를 실행하면 네 가정의 결과를 다시 계산합니다.
- **[운영안 비교 실험](http://127.0.0.1:8765/#simulation/evaluation)**은 가상 4현시 교차로에서 기준 고정 신호, 평균 수요로 조정한 시간대별 고정 신호, 직전 주기 관측에 반응하는 자동 배분을 비교합니다. 각 반복에서 동일한 차량 도착을 재사용합니다. 차량당 누적 대기, 종료·최대 대기열, 통과 대수, 방향별 변화와 짝지은 95% 신뢰구간을 확인하고 결과를 PDF로 인쇄하거나 JSON으로 저장할 수 있습니다.
- **[교차로 재생](http://127.0.0.1:8765/#simulation)**의 비교 화면은 일정 평균 수요, 시드 42의 첫 번째 반복에 해당하는 차량 도착·통과 기록을 재생합니다. 첫 주기는 기준 신호로 시작합니다. 단일 방식과 수동 조정은 설계서의 산식을 검토하는 기존 간이 계산을 사용합니다.
- **[현장자료 대조](http://127.0.0.1:8765/#simulation/field)**에서 CSV 작성 예시를 받아 관측한 녹색 구간, 방향별 초기 대기, 개별 도착 시각, 통과량과 종료 대기를 입력합니다. 입력한 조건에서 모형이 예측한 종료 대기와 관측값 사이의 오차를 계산합니다. 제공하는 예시는 합성 자료입니다. CSV 대조 예시에 쓰인 값은 둔대교차로 조사값과 별개입니다.
- **배경 지도**는 API 키 없이 표시할 수 있도록 시흥 일대의 도로, 토지 피복, 수계를 정적 지도로 렌더링했습니다. 2026년 11월 15일자 OpenFreeMap 벡터 타일을 사용했습니다. [OpenFreeMap](https://openfreemap.org/) · [© OpenMapTiles](https://openmaptiles.org/) · [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)
