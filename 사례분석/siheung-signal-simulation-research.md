# 시흥시 스마트교차로 연계 실시간 신호체계 시뮬레이션 분석 — 공개자료 조사

조사 기준일: **2026년 11월 13일**

## 1. 조사 결과

**해당 용역의 계약 사실을 시흥시정연구원 공식 공시의 첨부 PDF에서 확인했다.** 계약금액은 600만 원, 계약일은 2026년 9월 1일, 계약상대자는 주식회사 로디스다. PDF의 ‘계약기간’ 칸에는 **2026년 11월 30일**이 표시돼 있다. [공식 공시](https://www.shri.re.kr/news/biz-notice/detail/53) · [확보한 원문 PDF, 1쪽](sources/shri-contracts-2026-09.pdf)

다만 **과업지시서와 결과보고서는 이번 조사에서 확보하지 못했다.** 따라서 이 문서는 연구 결과 요약이 아니라, 확인된 계약정보와 관련 자료, 결과보고서를 확보한 뒤 분석할 항목을 정리한 조사 메모다.

민간 계약정보에만 의존했던 앞선 조사에서 한 단계 나아가 공식 근거와 계약기간 표기를 확보했다. 조사일은 공시된 11월 30일보다 이르므로, 연구 완료나 결과 공개 지연을 단정하지 않는다. 실제 착수·진행·검수 상태 및 기간 변경 여부는 별도 확인이 필요하다.

## 3. 무엇을 분석하는 용역인가

계약명으로 볼 때, **스마트교차로와 연계한 실시간 신호체계를 시뮬레이션으로 검토하는 분석 업무**로 해석할 수 있다. 구체적으로 어떤 자료를 받아 어떤 신호정책을 비교했는지는 공시되지 않았다.

특히 제목의 ‘실시간’이 다음 중 무엇을 뜻하는지 확인해야 한다.

- 실시간으로 수집된 교통량을 이용해 신호계획을 분석한다는 뜻인지
- 시뮬레이션 안에서 수요에 따라 신호를 계속 조정한다는 뜻인지
- 실제 교차로의 온라인 신호제어와 연계하는 연구인지

이 세 가지는 서로 다른 범위다. 계약명만으로 실제 도로의 자동 신호제어 시스템이 구축·운영됐다고 판단할 수 없다.

| 분석 항목 | 현재 확인 수준 | 필요한 자료 |
| --- | --- | --- |
| 대상 교차로·도로축 | 미확인. 둔대·장현·시청 일대 포함 여부도 미확인 | 대상지 목록, 위치도 |
| 입력 데이터 | 스마트교차로 연계라는 제목만 확인 | 교통량·대기행렬·영상·신호 로그의 항목과 수집 기간 |
| 기존 CCTV 활용 | 미확인 | 카메라 종류, 영상 입력 또는 집계값 입력 여부 |
| 신호 조정 변수 | 미확인 | 녹색 배분·주기·옵셋·현시 순서 변경 범위 |

| 비교 성과 | 미확인 | 기존 신호 대비 지체·대기·처리량 등 |

**이 용역이 SUMO, VISSIM, PSO, 강화학습 또는 특정 AI를 쓴다고 확인한 자료는 없다.** 아래 참고 논문의 방법을 이 용역의 방법으로 옮겨 적으면 안 된다.

## 5. 함께 읽을 관련 자료

### 5.1 시흥시 실측 자료를 이용한 2024년 학술논문

**박진환·허재석, 「공통 신호주기 제약을 고려한 Particle Swarm Optimization 기반 다중 교차로 교통 신호 최적화」**, 대한산업공학회지 50권 5호, 313–324쪽, 2024-10-15. [학회 원문](https://jkiie.org/_common/do.php?a=full&aidx=42247&b=21&bidx=3830) · [DOI](https://doi.org/10.7232/JKIIE.2024.50.5.313)

| 항목 | 논문에서 확인한 내용 |
| --- | --- |
| 자료 | 시흥시청 교통량과 시흥경찰서 신호정보 |
| 대상 | 연속된 교차로 3개, 각 5현시, 신호주기 165초 |
| 방법 | SUMO 시뮬레이션과 PSO 기반 녹색시간 최적화 |
| 제약 | 교차로 공통 주기, 정수 신호시간, 현시 순서 유지, 보행시간 고려 |
| 평가 | 시간대별 기존 신호와 제안 신호를 각각 100회 시뮬레이션 |
| 평균대기시간 감소율 | 출근 10.37%, 평시 20.229%, 퇴근 30.651% |

수치는 논문 표 4의 **시뮬레이션 결과**이며 실제 도로에서 측정한 개선율이 아니다. 이 논문과 2026년 로디스 용역의 발주·수행상 관계는 확인되지 않았다. 별도 선행연구로서 공통 주기를 유지한 녹색 배분과 반복 비교의 참고자료로 활용할 수 있다. [논문 5~6장](https://jkiie.org/_common/do.php?a=full&aidx=42247&b=21&bidx=3830)

### 5.2 시흥시 차량정보 수집·예측제어 실증

더로드아이앤씨의 정부 R&D 소개에는 시흥시 **9개 교차로의 개별차량 수집시스템**, **5개 교차로의 디지털 예측제어시스템** 구축·실증이 기재돼 있다. DSRC 수집장치와 신호제어기를 연계하는 설명도 있다. 관련 과제는 경찰청 발주·한국도로교통공단 주관, 연구기간 2021-04-01~2025-12-31로 소개된다. [참여기업 설명](https://the-road.co.kr/solutions/government-rnd/traffic-management/)

이 자료는 시흥에 다른 신호제어 실증 사례가 있다는 근거다. 이번 로디스 용역과 같은 대상지·시스템인지, 결과를 이어받은 연구인지, 현재 상시 운영 중인지는 확인되지 않았다. 9개소와 5개소의 중복 여부도 확인되지 않아 합쳐서 14개소라고 세지 않는다.

## 6. 우리 프로젝트와 비교할 핵심

우리 기획의 기준 문서는 [README-3.md](../README-3.md)다. 기존 고정형·PTZ CCTV로 방향별 수요를 측정하고, 주기·옵셋을 유지하면서 녹색시간을 배분하는 방식을 제안한다. 아래는 **비교 질문**이며, 로디스 용역에 해당 기능이 없다는 판단이 아니다.

| 비교 축 | 우리 기획 | 해당 용역에서 확인할 질문 |
| --- | --- | --- |
| 자료 확보 비용 | 기존 CCTV 재사용 | 스마트교차로 집계자료만 필요한가? 별도 검지장비가 필요한가? |
| 측정 신뢰도 | 가림·결측·PTZ 이탈 시 복귀 | 관측 오차를 반영했는가? 완전한 교통량을 가정했는가? |
| 제어 범위 | 녹색 배분, 주기·옵셋 유지 | 같은 범위인가? 여러 교차로를 함께 최적화하는가? |
| 주변 도로 영향 | 하류 막힘과 방향별 악화 확인 | 평균 개선과 함께 인접 교차로 악화도 평가했는가? |
| 평가 방식 | 동일 수요 반복 비교, 미진입 차량 집계 | 공정한 비교와 모형 보정을 어떻게 수행했는가? |
| 납품물 | 분석·권고 소프트웨어 지향 | 보고서·분석모형 납품인가, 운영 프로그램도 포함하는가? |

현재 확인된 사실로는 ‘시뮬레이션으로 신호 운영을 검토한다’는 문제의식이 겹친다. 차별성을 주장하려면 실제 데이터 접근 방식, 오류 대응, 성능, 유지관리 비용과 납품 범위를 비교해야 한다.

보고서를 확보하면 우선 **대상지 → 데이터 → 비교 신호정책 → 평가방법 → 결과 → 한계** 순서로 읽는다. 특히 평균대기시간 감소가 특정 시간대·방향에만 나타나는지, 종료 시 남은 차량을 제외해 결과가 유리해지지 않았는지, 관측 이후의 미래 교통량을 미리 이용하지 않았는지를 검토할 필요가 있다. 이는 향후 검토 기준이며 해당 용역의 결함을 확인했다는 뜻은 아니다.
